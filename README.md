# Black.Coach — releases

APK de Android e instalador de Windows de Black.Coach, entrenador personal.

- `manifest.json`: la app lo lee para saber si hay una versión nueva (campanita de actualización).
- Cada versión se publica como GitHub Release (`vX.Y.Z`) con `BlackCoach-X.Y.Z.apk` y `BlackCoach-Setup-X.Y.Z.exe`.

El código fuente está en el repositorio privado `black-coach`.
